- Held-aside TMs 28–35 of B4/UsCarrier/Cogentco were never used.

### 1.3 Implementation and hyperparameters

| Component | Setting |
|---|---|
| Candidate paths | Yen k = 4 (hop count) per OD pair; capacities and demands ÷ max link capacity |
| Policy (`recommended_stable`, frozen) | Phase-3 GNN on link–path bipartite graph, 4-way softmax per demand; Adam lr 5e-05, batch 1, ≤ 24 epochs, patience 6, seed 2026 |
| Policy v2 | same + calibrated-load training TMs + per-topology normalised selection score S |
| Twin | 5-member physics-anchored ensemble (hidden 32, dropout 0.1, lr 0.0005, weight decay 0.0001, anchor weight 0.01); conformal std scale 0.955 fitted on validation |
| Gate (frozen) | k = 1.0, utilisation limit 1.0, relative-σ veto None |
| Fallback (frozen) | shortest / equal, feasible first, else least-violating; conditional LP only in the LP-fallback study |
| P1 baseline | TopoFlowNet L = 6 + one-step A2C, 3 episodes, seeds 100–1000, ADMM ρ = 1.0, 2 iterations on B4 / 100 on GEANT (Teal-order headline) |
| Solvers | All LPs use SciPy HiGHS (scipy.optimize.linprog, method='highs'). No Gurobi licence was available, so Teal/FIGRET-style Gurobi LPs are replaced by HiGHS. |

*Source: `results/phase3_final/policy_v2/runs/v2_calload_normscore/config.json`; `results/phase3_final/e2_holdout_af/config_improved_stable.json`; `results/phase3_final/e4_twin_error/degraded_twins/config.json`; `baseline_p1_reproduction/BASELINE_FREEZE/logs/b4_freeze_summary.json`*

## 13. Scope and limitations

- The study does not include an 8-path fallback (generalised LP, max-flow screen) or the ASN topology.
- Policy v2 is a single training run: no hyperparameter grid, topology augmentation or actor-critic fine-tuning.
- The E3 link-failure experiment covers B4, GEANT and UsCarrier (not Cogentco or Kdl). The P1 GEANT reproduction has no ADMM stabilisation or B4 gap investigation; Teal, FIGRET and NCFlow were not run and are quoted from P1. The ablations contain no flat-MLP policy; the single-topology ablation uses the frozen P1 actor (confounded).
- UsCarrier and Kdl traffic matrices are synthetic all-ones toy templates; every index is an identical copy, so additional TM indices or seeds add no traffic diversity on these topologies.
- All LPs use SciPy HiGHS (scipy.optimize.linprog, method='highs'). No Gurobi licence was available, so Teal/FIGRET-style Gurobi LPs are replaced by HiGHS.
- The flow-level simulator is the ground truth for both twin labels and the oracle; no packet-level or real network validation was performed.
