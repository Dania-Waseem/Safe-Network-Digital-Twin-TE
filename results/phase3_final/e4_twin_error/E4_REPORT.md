# E4 twin-error sweep: mean-only gate (D) vs uncertainty-aware gate (E)

## Error models

1. **Member-wise perturbation** of the improved physics-anchored twin: `member_j(e) ← max(0, member_j(e)·(1 + σ z_j(e)))`, z ~ N(0,1), seed 4040, the same z for every σ and every gate, 3 replicates per case. μ and std are recomputed from the perturbed members, so ensemble spread grows with twin error. σ ∈ {0, 0.05, 0.10, 0.20, 0.40} (spec.json levels).
2. **Degraded twins**: physics-anchored ensembles trained with 10/25/50% of the train TMs and 1/2/4 epochs (`degraded_twins/`), evaluated as-is at σ = 0, each with its own validation-fitted conformal scale.

`spec.json`'s single-load perturbation is not used: it moves μ without changing the spread, which cannot test an uncertainty-aware gate fairly.

## Gates (identical inputs; utilisation limit 1.0)

A no gate · D mean-only (k=0) · Dm mean-only with a tighter limit L (control; L chosen on dev validation to be at least as conservative as E1) · E1 μ+1·c·std · E2 μ+2·c·std (c = frozen validation conformal scale) · E1r μ+1·c_σ·std with c_σ refitted per error level on the **dev validation** cases by the unchanged rule (smallest c with 2-std coverage ≥ 0.9; in-sample for dev, out-of-sample for GEANT/Kdl) · F physics oracle. Rejections use the frozen shortest/equal least-violating fallback.

Cases: dev = B4 val (8 TMs), UsCarrier val (1 TM), Cogentco val (8 TMs); holdout = GEANT (200 seeded test TMs), Kdl (1 TM). Each at fixed scales 0.25–1.0 and calibrated targets 0.5–1.1. UsCarrier and Kdl traffic matrices are synthetic all-ones toy templates; every index is an identical copy, so additional TM indices or seeds add no traffic diversity on these topologies.
